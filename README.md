# greet-community

A tiny greeting package with a contribution guide.

## Install

```bash
python -m pip install -e .
```

## Use

Import `greet` from `greet_community`.
- Run: `python -c "from greet_community import greet; print(greet('Hee'))"`
- Expected output: `Hello, Hee!`

See [CONTRIBUTING.md](CONTRIBUTING.md) to send a change.
